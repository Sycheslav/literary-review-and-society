# Repository skill entry point

Read and follow the canonical instructions in [content/agent-skill/SKILL.md](../../../content/agent-skill/SKILL.md). Keep detailed guidance in that one source; the site build publishes it at /literature/SKILL.md.

The public machine entry point is /literature/llms.txt. It links to the [English concept](https://socialgraph-labs.com/literature/knowledge/concept/en.md), [H1–H10 catalogue](https://socialgraph-labs.com/literature/knowledge/concept/hypotheses-en.md), accepted-analysis workflow, and earlier Russian knowledge routes. Treat the concept and hypotheses as working proposals, not findings. The English concept is delivered through the public static knowledge bundle and legacy search; it is separate from the registry-backed extraction API and `en-search` CLI.
