# Предложение пилота: восемь материалов

Кандидаты для обсуждения стандарта и будущего этапа 2, не назначения на обработку. Состав: четыре эмпирические работы разной сложности, обзор, теория, проект и материал с ограниченным доступом. Названия, наличие файлов и признаки результатов взяты из локального каталога и метаданных; оригиналы для этого отбора заново не прочитаны. Заявления о содержании и доступе требуют проверки при назначении.

| Роль | Существующий ID и материал | Зачем включить |
|---|---|---|
| Эмпирика, компактнее | `arxiv-2410-08948` — возникающие социальные конвенции и коллективное смещение | Локальная игра конвенций; разделение заданных правил и наблюдаемых норм. |
| Эмпирика, сети | `web-academic-oup-com-a58bb9960d` — формирование и динамика сетей между несколькими LLM | Выбор связей и операционализация структуры; проверить, насколько наблюдения поддерживают объяснения. |
| Эмпирика, смешанные исходы | `arxiv-2404-16698` — Cooperate or Collapse / GovSim | Общий ресурс, контроль коммуникации и неоднородности; по карточке есть негативные и смешанные исходы. Проверить числа и условия в оригинале. |
| Эмпирика, сложнее | `arxiv-2606-07513` — Agentopia | Несколько миров и обучение по траекториям; по карточке есть разнонаправленные показатели. Испытать учёт разных условий, версий и ограничений. |
| Обзор | `arxiv-2504-03274` — критический обзор генеративных социальных симуляций | Проверить профиль обзора, поиск и границы синтеза. |
| Теория | `arxiv-2310-10826` — Mechanism Design for Large Language Models | Формальные предпосылки и доказательства без искусственного требования LLM-прогонов. |
| Проект | `github-agentciv-agentciv` — AgentCiv | Отделить заявленные возможности и демонстрацию репозитория от независимой оценки. Метаданные говорят `repository`; локальный путь fulltext отсутствует. |
| Ограниченный источник | `web-iclr-cc-8e103da977` — как LLM меняют равновесие в аукционах | Проверить честный частичный пакет: в метаданных `limited`, локальный полный текст отсутствует; перед обработкой перепроверить законную доступность. |

У остальных шести метаданные заявляют `fulltext` и путь к локальному тексту обнаружен; это не проверка полноты extraction, приложений или достоверности. До начала пилота зафиксировать версию контракта, роли, доступные источники, бюджет и условия остановки; запуск оплачиваемых внешних API не разрешён этим предложением. Рецензенты независимы от авторов пакетов. Измерять время, токены, стоимость, ошибки и согласие оценщиков; при недостаточном качестве Luna Max не начинать массовую обработку без изменения процесса или решения владельца.
