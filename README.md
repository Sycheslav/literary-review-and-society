# Социумы ИИ-агентов — карта исследований

Минималистичный веб-интерфейс для совместного изучения литературного обзора Лаборатории № 57 ИПУ РАН. В центре — связи между исследованиями, темами, методами, платформами и данными; карточки работ ведут к подробным разбираемым фрагментам и исходным материалам.

## Что умеет сайт

- интерактивный граф знаний на `vis-network` с переходом от узла к узлу;
- каталог работ, поиск по корпусу, авторам, годам и темам;
- иерархическое оглавление и раскрываемые фрагменты, а также режим чтения полного текста;
- ссылки на первоисточники и пометки о том, что именно проверено;
- общие комментарии к работам и фрагментам текста с возможностью модерации владельцем.

В корпусе сайта сейчас 389 работ, 13 тем, 1 306 узлов графа и 1 995 связей. Материалы — рабочий исследовательский корпус, а не исчерпывающий систематический обзор. Слова «социум» и «дружба» используются как исследовательские понятия и сами по себе не свидетельствуют о сознании или человеческих чувствах у моделей.

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Next.js (обычно `http://localhost:3000`). Каталог и материалы работают без базы. Для общих комментариев задайте `DATABASE_URL` на PostgreSQL и `MODERATION_KEY` для удаления сообщений владельцем. Схема `literary_review` создаётся приложением при первом обращении к API комментариев.

## Railway

Проект развёртывается в окружении Railway `small projects` → `production`. Веб-сервис использует Node.js и команды `npm run build` / `npm start`. Для комментариев ему нужна переменная `DATABASE_URL`, ссылающаяся на PostgreSQL сервиса проекта, и секретная переменная `MODERATION_KEY`.

Приложение отделяет свои таблицы в PostgreSQL схемой `literary_review`; существующие схемы базы не затрагиваются. Корпус и индекс поиска входят в репозиторий в `public/corpus/` и обслуживаются как статические файлы.

## Обновление корпуса

`scripts/prepare-corpus.mjs` пересобирает браузерный снимок из исходников литературного обзора, размещённых рядом с папкой сайта: `graph.json`, `navigation.json` и связанные Markdown-файлы. Перед обновлением проверьте изменения в `public/corpus/` и `public/corpus/manifest.json`.
