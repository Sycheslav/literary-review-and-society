# Социумы ИИ-агентов — обзор исследований

Сайт для совместного изучения литературного обзора Лаборатории № 57 ИПУ РАН: исследования и проекты о группах языковых агентов — связи, роли, нормы, институты, коллективная память.

## Структура сайта

- `/` — главная: вход в концепцию, восемь работ «с чего начать», двенадцать обобщений по корпусу, направления, карта связей;
- `/concept`, `/concept/[глава]` — «Концепция и идеи исследований»: 23 главы общего документа проекта;
- `/topics/[id]` — направление: вводный очерк и работы по значимости;
- `/works` — каталог с поиском и фильтрами; при наведении на название показывается аннотация;
- `/works/[id]` — карточка работы: аннотация, главные результаты, выводы, подробности в раскрывающихся разделах, ссылка на первоисточник, обсуждение;
- `/works/[id]/text` — полный текст оригинала, извлечённый из PDF;
- `/graph` — карта связей с фиксированной укладкой.

На сайте 281 работа и 13 направлений. Из исходного корпуса (389 записей) убраны второстепенные работы до 2024 года и вторичные материалы, а репозитории, наборы данных и копии текстов показаны ссылками в карточках основных работ — см. `data/curation.json`. Слова «социум» и «дружба» используются как исследовательские понятия и сами по себе не свидетельствуют о сознании или чувствах у моделей.

## Данные

Сайт читает готовые файлы из `data/`:

| Файл | Содержание |
|---|---|
| `works.json` | список работ: русское и оригинальное название, авторы, год, направления, аннотация |
| `details.json` | разделы карточек, главные результаты, ссылка на первоисточник, путь к полному тексту |
| `topics.json` | направления и вводные очерки |
| `graph.json`, `layout.json` | узлы, связи и зафиксированные координаты карты |
| `translations.json` | русские переводы названий и разделов карточек |
| `curation.json` | ревизия корпуса: исключённые записи с причинами, присоединённые артефакты, поправки названий и значимости |
| `concept.json` | главы концепции, собранные из `content/concept.md` |

Исходный корпус лежит в `public/corpus/` (`graph.json` и Markdown-файлы карточек, очерков и полных текстов). Пересборка данных:

```bash
python scripts/merge_translations.py data/translations-src <папка с исходными пакетами>   # при новых переводах
python scripts/layout_graph.py    # укладка карты (нужен networkx)
python scripts/build_data.py
python scripts/build_concept.py   # после обновления content/concept.md
```

Переводы названий и разделов выполнены автоматически и требуют выборочной вычитки; числа в переводах сверены с исходными карточками скриптом.

## Локальный запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Для общих комментариев задайте `DATABASE_URL` (PostgreSQL) и `MODERATION_KEY` (удаление комментариев владельцем). Таблицы создаются в схеме `literary_review` при первом обращении к API.

## Railway

Проект развёрнут в окружении Railway `small projects` → `production`, команды `npm run build` / `npm start`; переменные `DATABASE_URL` и `MODERATION_KEY` заданы в сервисе.
