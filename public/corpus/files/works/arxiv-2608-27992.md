## Короткая аннотация

GOD — local-first operator/control-room система для симуляций общества агентов, объединяющая setup wizard, Agent Studio, Map Studio, карту/таймлайн replay, commands Ask/Intervene и переносимые packs. Основное техническое предложение — связать вмешательство оператора с последующим состоянием симуляции и общей записью команды в replay. Оценка проверяет 15 run slots и корректность командно-артефактного цикла, а не интеллект/валидность поведения общества.

## Дизайн исследования

Инструмент интегрирует AgentSociety simulator с JiuwenClaw runtime и добавляет React/Vite browser control room плюс FastAPI backend. Setup wizard выбирает scenario/map/agent profiles; Agent Studio редактирует жителей, Map Studio — карту, локации и collision constraints. Каждый step агент наблюдает местоположение, клетки, соседей, недавние сообщения, interaction affordances, public event и pending operator interventions; system prompt включает identity, routines, relationships, needs, worries, quirks, recent history и mounted skill cues. JiuwenClaw выбирает executable skill из catalog, выдаёт structured result, среда применяет его через pathfinding, взаимодействие с объектом, direct/group messages, state updates, memory effects, затем записывает replay frame. Ask — read-only интервью; Intervene — instruction/event в следующий prompt/step; команда хранится вместе с target, текстом, result/time/step. Replays statically package timeline/map/profile/command records; experiment/map/agent packs отдельно дают воспроизводимую конфигурацию без API keys, локальных runtime snapshots и credentials. Полная заявленная 22-agent benchmark series использует fixed PKU map, 22 profiles и Qwen-Plus; 15 completed run slots включают один baseline и 14 event/movement intervention runs из 10 templates, часть повторена дважды. Проверяют event routing, trace@2, commanded destination, state answers/replay match и event boundary. Это system/evaluation platform, а не controlled claim о культурном поведении LLM.

## Техническая реализация

Работа не вводит новый agent policy, memory/planner или base simulator, а интегрирует React/Vite, FastAPI, AgentSociety и JiuwenClaw v0.1.11; локальная модельная endpoint задаётся оператором. В benchmark все прогоны на Qwen-Plus через DashScope endpoint, температура не override (provider defaults); число агентов — 22, demo Town отдельно имеет 10 residents. Prompt включает resident profile, world context, skills, pending interventions и наблюдение. Публичные packs не содержат API keys, локальной конфигурации, runtime snapshots или replay database. Hosted replays доступны для read-only просмотра; edits/live commands требуют локального запуска. Репозиторий содержит trimmed AgentSociety/JiuwenClaw subtrees.

## Промпты и инструкции

Точные промпты шага передают profile/world state/nearby agents/recent messages/latest public event/available actions/pending operator instructions; выбранный skill schema ограничивает допустимый тип операции. Ask вызывает external-question path от первого лица на текущем времени; Intervene вкладывается в prompt следующего шага или рассылается через event publisher. Это управляемые operator interventions, а не доказательство внутренних желаний агента. Публичный replay сохраняет текст команд, но авторы отмечают, что строковые проверки ответа не доказывают semantic grounding.

## Опубликованные расходы и вычисления

Публикуемые расходы API и токены не найдены. Run использует Qwen-Plus через DashScope, но paper не указывает суммарный расход или токенизацию; локальная first-party infrastructure/compute тоже не оценена в деньгах.

## Результаты

В 15/15 planned benchmark run slots завершены; 14/14 event commands маршрутизированы не как movement actions. Event-specific trace@2 — 212/308 agent-runs; цель зафиксирована после одного шага у 78/84 target checks; 23/224 non-target checks также были у заданной точки. 169/182 ответов строково совпали с saved location/action; 144/182 прошли event-boundary string match; 0/392 unsupported location strings, 9/252 post-answer role-anchor misses. Pre-event leakage 0/140. Повторяемость локации pairwise JSD=.011. Авторы подчеркивают, что фиксированные профили не независимые люди, interviews повторяются у одних и тех же жителей, deterministic string matches не устанавливают правдивость/grounding, а 22 resident runs — проверить pipeline fidelity, не социальную валидность.

## Выводы авторов

Авторы позиционируют вклад как операторский путь воспроизводимости и инспекции: команда, вмешательство, live state и replay связываются общей schema, а experimental inputs отделяются от runtime data. Они явно не утверждают, что система повышает качество отношений или поведенческую реалистичность агентов.

## Ограничения и интерпретация

Статья не сравнивает модельные политики и не валидирует social-science constructs; benchmark автоматизирован и deterministic text checks не дают семантического доказательства. Один provider/backend Qwen-Plus, фиксированный набор профилей/карты и небольшая серия; denominators повторно используют 22 residents, не независимые субъекты. Нельзя трактовать trace@2, destination record или string match как эмпирический эффект агента. Не было human-subject usability study.
