## Короткая аннотация

Репозиторий предоставляет стенд, конфигурации, снимок состояния и экспорт прогона для воспроизводимого наблюдения за виртуальной цивилизацией агентов. Это software artifact, а не независимая научная статья.

## Дизайн исследования

Использовать как симуляционную платформу/данные: инвентаризировать правила мира, agent initialization, persistence, turn schedule, communication channels and scoring from config before treating observed behavior as emergent. Snapshot/run export allow audit of state, but a single trajectory cannot establish general emergence.
