## Короткая аннотация

Melting Pot — набор из более 50 многоагентных игр и более 256 тестовых сценариев для оценки обобщения в новых социальных взаимодействиях. Это не LLM; проект может служить средой для многоагентного RL и основой для адаптера (оценка редакции).

## Дизайн исследования

Содержит более 50 многоагентных игр (substrates) и более 256 тестовых сценариев (README); агенты обучаются с подкреплением. Разработано для RL benchmark, поэтому использование с LLM требует интеграции и отдельной проверки интерфейса/actions.
