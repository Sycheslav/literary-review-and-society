# StanfordHCI/genagents

[К главному обзору](../README.md) · [Методология, валидация и сравнение с людьми](../topics/methodology.md) · [Коллективная память, язык и культурная передача](../topics/memory.md) · [Коллективный интеллект, дебаты и конформизм](../topics/intelligence.md)

## Коротко

> Код архитектуры генеративных агентов, которые отвечают на опросы от имени реальных людей на основе качественных интервью и демографического банка GSS.

- **Значимость для обзора:** дополняющая — Важный методологический источник о симуляции индивидов на основе интервью, но не о взаимодействии агентов в социуме; связь с темой обзора косвенная (валидация и репрезентативность).
- **Число агентов:** 1000 интервью-агентов (полный банк не опубликован); более 3000 демографических агентов GSS в открытом банке
- **Модели:** gpt-4o-mini
- **Ключевые слова:** generative agents, interview-based agents, survey simulation, GSS, memory stream, reflection, gpt-4o-mini

**Главные результаты**

1. README: агенты строятся по качественным интервью о жизни людей и воспроизводят ответы этих людей на социально-научные измерения; заявлено около 2000 часов интервью и 1000 агентов (в полный банк не публикуется).
1. В открытом репозитории есть банк демографических агентов по General Social Survey (GSS) более 3000 агентов и один пример агента-автора; имена и адреса в GSS-банке, по README, вымышленные.
1. Открытый код решает задачи опросов: категориальные, числовые и открытые ответы, память (memory stream) и рефлексия; многоагентной среды или взаимодействия агентов между собой в README не описано.
1. Доступ к полному банку ограничен по соображениям приватности: агрегированные данные по фиксированным задачам и индивидуальные ответы по открытым задачам по запросу с этической проверкой.

## Дизайн исследования

По README исследование основано на качественных интервью: участники рассказывали о своей жизни по протоколу интервью, а агент строит модель личности на этом материале. Затем агенту задают вопросы социально-научных опросов (категориальные варианты, числовые шкалы, открытые вопросы) и сравнивают ответы агента с ответами реального участника. В самом README не приведены ни протокол интервью, ни число вопросов, ни метрики точности, ни схема выборки, ни процедура сравнения: эти сведения отсылаются к статье Park et al. (2024). Открытая часть проекта включает два компонента: инструменты для создания и опроса агентов по собственным данным и банк 3000+ демографических агентов, построенных на GSS. Ещё один пример — агент одного из авторов, созданный по тому же протоколу интервью. Полный банк на 1000+ агентов публично не опубликован. Социальная среда, множество агентов, которые общаются друг с другом, и временная динамика симуляции в README не описаны.

## Техническая реализация

Требования по README: Python 3.7 и выше; API-ключ OpenAI с доступом к GPT-4 или GPT-3.5-turbo. В примере конфигурации (settings.py) задан LLM_VERS = "gpt-4o-mini", то есть в коде по умолчанию используется другая модель, чем указано в требованиях, и это расхождение стоит отметить. Параметр MAX_CHUNK_SIZE = 4 задаёт размер порции при обработке. Структура репозитория: модуль genagents (класс GenerativeAgent, interaction.py, memory_stream.py), каталог simulation_engine (settings, global_methods, gpt_structure, llm_json_parser и каталог prompt_template со всеми LLM-промптами), каталог agent_bank с популяциями gss_agents и single_agent. Память: поток наблюдений (remember с временным шагом time_step) и рефлексия по якорю (reflect(anchor=..., time_step=...)); агент сохраняется и загружается из папки (save / agent_folder). Версии библиотек фиксируются в requirements.txt, который в тексте README не раскрыт. Расписание, параллелизм и инфраструктура для многоагентных экспериментов в README не описаны.

## Промпты и инструкции

Все LLM-промпты, как указано в README, находятся в каталоге simulation_engine/prompt_template/. Их точные тексты в проверенном тексте README не приведены; для анализа нужно открыть репозиторий. Пример вызова: agent.categorical_resp с вариантами ответа, agent.numerical_resp с диапазоном [1, 10], agent.utterance с диалогом интервьюера. Разграничение между промптами, которые задают личность, и промптами, которые задают ответ на вопрос, в README не описано.

## Выводы авторов

Авторы README заявляют, что агенты, построенные по интервью, воспроизводят ответы участников на социальные измерения и могут служить основой для инструментов изучения индивидуального и коллективного поведения. Это заявление о назначении проекта, а не проверенный вывод. Интерпретация «коллективного поведения» здесь относится к агрегированию индивидуальных ответов, а не к взаимодействию агентов.

## Ограничения и интерпретация

Открытый код не содержит полного банка интервью-агентов, поэтому воспроизвести основной результат статьи на открытых данных нельзя. Требуется доступ к OpenAI API, то есть исследование зависит от закрытой модели и её версии. Агенты отвечают на опросы, а не действуют в среде; для вопросов о связях, ролях и нормах социума этот подход не даёт прямых данных. Заявление о точности воспроизведения интервью и валидности опросных измерений должно проверяться по статье, а не по README.
