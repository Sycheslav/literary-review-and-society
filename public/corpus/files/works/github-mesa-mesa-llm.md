## Техническая реализация

Установка через pip (пакет mesa-llm; для предрелизных версий опция --pre; также установка из git в режиме редактируемого пакета). Поддерживаемые провайдеры LLM по README: OpenAI, Anthropic, xAI, Hugging Face, Ollama, OpenRouter, Novita AI и Google Gemini. Таким образом, на одном стенде теоретически доступны и облачные API, и локальные модели через Ollama, и маршрутизатор OpenRouter, который интересен для дешёвых моделей. Конкретные идентификаторы моделей, способ выбора провайдера, управление памятью агентов, механизм коммуникации, расписание и хранение состояния в README не описаны. Версия библиотеки не зафиксирована, поскольку README предупреждает о возможных изменениях API. Сведения о CI (GitHub Actions), покрытии тестами (Codecov), линтинге (Ruff) и сборке (Hatch) относятся к инженерной инфраструктуре и не влияют на научные выводы.
