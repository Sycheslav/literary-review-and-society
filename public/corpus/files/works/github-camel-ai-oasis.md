## Короткая аннотация

OASIS — симулятор социальных платформ в стиле Twitter и Reddit с LLM-агентами, нативными действиями платформы, рекомендательными системами, часами и журналированием состояния. В README заявлен масштаб до миллиона агентов; это целевой предел программной платформы, а не утверждение, что в каждом запуске одновременно активны миллион LLM. OASIS — инфраструктура для экспериментов, а не отдельный эмпирический результат.

## Дизайн исследования

Пользователь задаёт профили агентов и граф, выбирает тип платформы, набор действий и систему рекомендаций, затем двигает симулируемое время шагами среды. Агенты могут публиковать, ставить отметки, подписываться, комментировать, репостить и выполнять другие действия; платформа показывает реакции и контент. Два стандартных типа платформы воспроизводят возможности Twitter и Reddit; также поддерживаются пользовательские конфигурации. SQLite хранит действия и связи, масштабирование времени Clock задаёт ход симуляции. Допускаются различные модели, инструменты и prompts для агентов; фиксированного экспериментального протокола нет. В каждой работе нужно задавать размер популяции, стартовые профили, расписание шагов, ленту, действия и модель.

## Техническая реализация

README CAMEL-AI/oasis заявляет масштаб до 1 млн пользователей и 23 действия. Конфигурация документации включает agent_graph, platform, database_path, semaphore (по умолчанию 128), профили пользователей, набор действий и необязательные embedding/recommendation. SocialAgent наследует CAMEL ChatAgent и содержит сведения о пользователе/память. Есть случайные рекомендации, рекомендации Reddit по вовлечённости, персонализация Twitter и опциональные графовые эмбеддинги TWHin. Поля профиля user_char/description становятся исходным текстом идентичности в system prompt. Платформа предоставляет примитивы (профиль, граф действий, постоянные журналы), но автоматически не гарантирует социальное поведение.

## Промпты и инструкции

Framework принимает индивидуальные prompts и данные профилей; универсального prompt нет. Встроенная схема профиля задаёт начальные поля идентичности. Для воспроизводимости исследователь должен архивировать выбранные профили, версии prompt, model ID и конфигурацию ленты.

## Опубликованные расходы и вычисления

Единой цены API нет: доступны разные провайдеры моделей, размеры популяции, временные масштабы и смеси действий. Миллион заявленных агентов не означает миллион одновременных запросов к модели; требуется отчёт конкретного эксперимента. Страница репозитория не содержит счёта за benchmark.

## Результаты

Исходная статья/репозиторий описывают масштабируемость и дают примеры/учебные материалы; это функциональность ПО, а не свидетельство точного воспроизведения реального общества. Сценарии применения надо проверять отдельно на контролируемые исходы. В changelog видны добавления по версиям (групповые чаты, интервью, настройка моделей/инструментов/prompts, публикация отчётов), поэтому важна версия кода.

## Выводы авторов

OASIS полезен как воспроизводимая платформа взаимодействий на уровне социальной сети, поскольку делает явными действия, рекомендации и логи данных. Рекомендации и активацию следует рассматривать как экспериментальные факторы, а не технические детали.

## Ограничения и интерпретация

Заявление README о масштабе не является социальной валидацией. Один пользователь может создавать много модельных вызовов; асинхронная параллельность и показ ленты определяют фактические взаимодействия. Профили и рекомендации заранее направляют поведение; память может предоставляться каркасом. Открытый код не гарантирует бесплатность используемых моделей/API или данных.
