## Короткая аннотация

GlossoGen — платформа для сценариев с несколькими LLM-агентами, где задаются роли, каналы, инструменты, раунды и выбранные исследователем метрики. Система записывает сообщения, вызовы инструментов и ответы моделей; встроенные сценарии исследуют коммуникацию под ограничением информации и бюджета символов. Репозиторий связан с исследовательской статьей о возникновении языка в сложных межагентных взаимодействиях.

## Дизайн исследования

README позиционирует проект как среду контролируемых экспериментов: несколько агентов решают симулированную задачу с личными ролями, каналами и инструментами; взаимодействие идет по раундам, а все сообщения/вызовы инструментов/ответы сохраняются для последующего подсчета метрик, которые задает исследователь. Готовые сценарии изучают коммуникацию под давлением, где ни один участник не имеет полной информации, а во многих сценариях каждое отправленное сообщение расходует посимвольный раундовый бюджет. Поэтому агенты вынуждены сокращать сообщения, пользоваться аббревиатурами или формировать shorthand. Репозиторий предоставляет контролируемую игровую среду, а не независимый результат paper.

## Техническая реализация

В README заявлены Python 3.14, установка через закрепленный Git tag (пакет не опубликован в PyPI), документация по UI, запуску, fork/swap вмешательствам, сценариям и метрикам. Есть event-sourced run log для воспроизводимого анализа, а проект предоставляет демонстрацию и возможность упаковать собственные scenario/metric. Публичный README связывает систему с GlossoGen paper и репозиторием emergent_communication; кодовую архитектуру следует читать отдельно от научных результатов.

## Промпты и инструкции

README не задает единый prompt: роли, каналы и инструменты определяются сценарием. Исследователь сам выбирает метрики и формулировки заданий. Полные prompts конкретной статьи принадлежат связанному paper/data; нельзя считать шаблон платформы неизменной процедурой для всех экспериментов.

## Опубликованные расходы и вычисления

README не публикует стоимость API или нормативный токен-бюджет платформы. Встроенные примеры часто ограничивают число символов на раунд — это экспериментальное правило, не денежная цена API.

## Результаты

В репозитории нет отдельной численной научной оценки платформы. Его технический вклад — event log, контролируемые сценарии, вмешательства смены/ветвления истории и постфактум метрики. Наблюдения о возникновении shorthand проверяются по связанной статье, а не выводятся из факта наличия кода.

## Выводы авторов

GlossoGen полезна как воспроизводимая инфраструктура, которая позволяет фиксировать сообщения и систематически менять связи/историю/бюджет. Она делает исследовательские условия явными, но сама по себе не доказывает социальные выводы.

## Ограничения и интерпретация

README не является полным текстом paper и не доказывает корректность любой метрики. Для установки требуется Python 3.14 и фиксация версии tag; сценарии ограничены авторами, число символов выступает искусственным ограничением. Результаты зависят от конкретной модели и prompt-содержимого.
