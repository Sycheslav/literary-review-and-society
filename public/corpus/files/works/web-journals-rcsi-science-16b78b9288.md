## Короткая аннотация

Статья описывает хакатон УБС Challenge’2024 по прогнозированию общественного мнения из высокогранулярных данных ВКонтакте. Используются Abelson model, regressions и ensembles; LLM не применяются. Это полезная baseline для сравнения с генеративной симуляцией.
