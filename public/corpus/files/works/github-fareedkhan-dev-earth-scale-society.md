**Главные результаты**

1. README описывает один ноутбук из 92 ячеек для сборки и запуска симуляции.
1. Заявленная популяция — 1 млрд агентов из пула 10 000 персон; возможны 900 млн комбинаций говорящий–слушатель–позиции.
1. Модель-учитель используется офлайн для заполнения таблицы; runtime применяет lookup, поэтому проект не моделирует онлайн-диалог миллиардов LLM.
