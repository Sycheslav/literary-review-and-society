## Короткая аннотация

YuLan-OneSim представлен как платформа для моделирования человеческого социального поведения с помощью LLM-агентов. README заявляет конструирование сценариев на естественном языке, более 50 типовых сценариев в восьми областях, улучшение симуляций по внешней обратной связи, поддержку до 100 000 агентов и модуль AI social researcher. Это заявления о возможностях платформы, а не независимая валидация всех симуляций.

## Дизайн исследования

README описывает платформу для social science and AI, где сценарии создаются в естественно-языковом диалоге и запускают агентные модели; библиотека содержит более 50 стандартных сценариев в восьми областях. Система заявляет evolvable simulation, где модель автоматически улучшается от внешней обратной связи, large-scale simulation с распределенным исполнением и AI social researcher, который может пройти путь от постановки темы до отчета. Это перечень функций по документации, а не протокол одного эксперимента с человеческой контрольной группой.

## Техническая реализация

Репозиторий содержит Docker-конфигурацию, web UI на localhost:8000, настройки ключей/endpoint в `config/config.json` и `config/model_config.json`, docs и Docker Hub image. Требуется Python 3.10+ (или Docker). README предлагает несколько API провайдеров через конфигурацию и опубликовал arXiv 2505.07581 при релизе 2025-05-13. Конкретные модели/механизмы сценария надо сверять в статье и docs.

## Промпты и инструкции

Сценарии задаются естественным языком; пользователь настраивает модель/ключи, платформа превращает сценарий в симуляцию. README не раскрывает единый prompt шаблон для всех сценариев или полные runtime prompts; каждый сценарий может давать другие инструкции.
