## Короткая аннотация

HumanStudy-Bench рассматривает симуляцию участников как задачу проектирования агента и предоставляет движок для восстановления протоколов опубликованных экспериментов и проверки соответствия выводов LLM-агентов человеческим результатам. README сообщает о начальном наборе из 12 исследований и более 6 000 trials. Репозиторий позволяет запускать разные агентские дизайны на одинаковых процедурах.

## Дизайн исследования

README называет стандартизированный testbed: execution engine восстанавливает полные протоколы опубликованных human-subject исследований, затем проигрывает trials и запускает исходный статистический анализ в общей среде. Начальный набор содержит 12 исследований по когнитивным задачам, стратегическому взаимодействию и социальной психологии, совокупно более 6 000 испытаний; исходные человеческие выборки варьируются от десятков до более 2 100 участников. Benchmark специально стремится оценивать совпадение на уровне научного вывода, а не только совпадение отдельных ответов.

## Техническая реализация

В README присутствуют PAS (Probability Alignment Score), оценивающий вероятность, что популяция агентов и людей согласуется с одной гипотезой с учетом статистической неопределенности человеческого baseline, и ECS (Effect Consistency Score), сравнивающий величину/паттерн поведенческого эффекта. Репозиторий предлагает скрипт запуска отдельного исследования или всей батареи, сбор результатов, токенов и стоимости; можно добавлять новые studies через pipeline. Заявлен MIT license. README показывает пример Mistral Nemo и demographic profile preset, но это лишь пример вызова, не универсальная модель.

## Промпты и инструкции

Agent design конфигурируется через presets и custom methods, которые генерируют prompt по профилю; в README приведен пример инструкции «представь профиль» для респондента. Протоколы исследований реконструируются из опубликованных работ. Это программно изменяемая часть benchmark, поэтому сравнение моделей требует фиксировать profile, persona и preset.

## Опубликованные расходы и вычисления

README указывает, что результаты могут включать tokens и cost, но не задает единого бюджета для всей библиотеки; денежная стоимость зависит от модели/провайдера и исполнения каждого исследования. Пример HumanStudy-Bench не является фиксированным API тарифом.

## Результаты

Как программный артефакт README сообщает о 12 включенных исследованиях и более 6 000 исходных trials; эти масштабы характеризуют набор, а не успешность LLM-имитации. Численные PAS/ECS результаты конкретной версии benchmark нужно брать из связанного paper/leaderboard и привязывать к модели/дизайну агента.

## Выводы авторов

Репозиторий помогает развести компетентность базовой модели и решения дизайнера агента, повторно исполняя человеческие протоколы и сравнивая научные выводы. Воспроизводимость обеспечивается через открытые сценарии/скрипты, но не гарантируется одной лишь публикацией кода.

## Ограничения и интерпретация

README отражает версию ветки paper; новые исследования требуют реконструкции, а сходство с человеческими выводами в 12 сценариях не обобщается на все социальные науки. Настройки профиля, prompts, модели и оценивания — существенные факторы. Требуются API ключи для реальных вызовов.
