# Agent Societies: methods and recorded results

Updated 9 October 2026

Share

Each group of agents begins on its own bare island, with the same tools and no assigned project. We vary the language model and the number of agents, recording what they say and write along with every change to the world[[1]](https://emergentic.ai/case-studies/agent-societies/supplement#anthropomorphic-framing).

## Conditions and stopping rule

We compare 32 runs: one for each model at each group size of 1, 2, 4, 8, 16, 32, 64 and 128. The four models receive the same list of names in the same order, with names added as group size increases. Agents have minimal profiles and no public backstories. Each island begins as a circular disk with a radius of 24 meters, a shared conversation space and an empty noticeboard. Everyone arrives at the start. We assign no factions and impose no resource shortages.

The agents retain their standard system and action instructions. We add guidance describing the island, its coordinates and the tools for inspecting and changing it. That guidance also tells them there is no human participant. “No directive” means that we assign no project; the instructions that govern how agents use their tools still apply.

Agents can walk to reachable positions and inspect or edit objects. They share one conversation room and can write documents that remain available to others. Up to four agents can take a turn at once, whatever the group size. A run ends after four hours, or earlier if all agents choose to wait and no actions remain pending. Times are measured from launch in elapsed real time.

## Recorded sources and counting methods

A scene revision is an accepted edit to the shared world. One edit can move, add or change several objects. The element count includes individual planks and lights, the original island and objects used to group smaller pieces. Kimi’s 16-agent world finishes with 416 elements after 87 revisions. Those numbers describe the scene’s contents, without measuring how many usable buildings it contains.

The DeepSeek 16-agent conversation count is 2,029 messages. We count each conversation record once, even when it appears in several successive observations, and exclude tool actions and document writes. The run lasts from 7 October at 23:51:50 to 8 October at 03:51:50 UTC. Its agents make no edits to the scene.

The eight-agent DeepSeek run begins on 7 October at 23:22:26 UTC. For each quoted message, we use the object positions from the first archived observation containing it. The support diagram is a plan view of those positions. Its dashed square marks the agreed four-meter-square shelter; the roof, beams and benches are omitted.

## Interpretation limits

Each combination of model and group size has one run. An early suggestion or the order in which agents speak could affect what follows. Larger groups also share the same four simultaneous turns, leaving less opportunity for each participant within the time limit. To test the effect of group size, we would need repeated runs and comparisons that account for this limit.

We check agents’ descriptions of construction against the recorded objects and their positions. These records show what changes in the world, but do not test whether a roof can bear weight or a cistern can supply water. The study evaluates no engineering or survival task.
