# Сведения из исходного корпуса

> Это прежние обзоры проекта, а не оригинальный текст авторов. Утверждения могут быть исправлены в основной карточке.

## note

Источник: `Социумы ИИ-агентов программа исследований Лаб. 57 ИПУ РАН × «Верхум».md`, строка 24. Фрагмент относится сразу к нескольким источникам; не все его числа можно приписывать этой работе.

- Название: Лаборатория № 57 «Активных систем». Заведующий: А.Г. Чхартишвили (по тексту страницы, с 2020 г.). Основатель направления: В.Н. Бурков.
- Официальные направления: механизмы управления мультиагентными активными системами; многоуровневые системы и синтез структур, включая сетевые; информационное управление с учётом рефлексивного поведения агентов; модели управления в онлайн-соцсетях; управление проектами; комплексное оценивание; теория эволюционного развития.
- Опорные работы: монография Chkhartishvili, Gubanov, Novikov «Social Networks: Models of Information Influence, Control and Confrontation» (Springer, 2019); обзор Новикова и Чхартишвили по рефлексии ([ijassa, 2014](https://ijassa.ipu.ru/index.php/ijassa/article/view/401)); цикл Новикова и Словохотова «Распределённый интеллект мультиагентных систем» («Проблемы управления», 2023, по списку трудов на [ipu.ru/staff/novikov](https://www.ipu.ru/staff/novikov)); работы И.В. Козицина по моделированию социального влияния и онлайн-сетей ([ipu.ru/node/83140](https://www.ipu.ru/node/83140)).
- Публикаций лаборатории именно про LLM-агентов в открытых источниках не нашлось. Это не доказывает их отсутствия, но значит, что ниша для лаборатории свободна.
- Прямой связи ИПУ РАН с проектом verhum.org в открытых источниках не нашлось. На сайте проекта есть ИИ-агент, который проводит «верхум-анализ», и Telegram-сообщество; исследовательской повестки там не опубликовано.
