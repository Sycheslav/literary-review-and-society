Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 77.

**Oppy, практический запуск Concordia**, октябрь 2026. [Статья с описанием и журналами настройки](https://zenn.dev/taka4/articles/f38aad4ba71088). Автор сообщает о запуске локальной модели Qwen3 14B через Ollama: пять шагов заняли примерно 8,8 минуты на ноутбуке без GPU; описана несовместимость некоторых thinking-моделей с принудительным JSON и предложена настройка `think: false`. Это единичный опыт и не бенчмарк для двадцати агентов; он полезен для планирования пилота и оценки совместимости. Страница автоматически переводится с японского, поэтому технические детали рекомендуется сверять с оригиналом и на собственной версии ПО.
