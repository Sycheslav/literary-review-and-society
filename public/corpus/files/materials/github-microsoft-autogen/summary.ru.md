# AutoGen: фреймворк многоагентных диалогов

**Проект:** `microsoft/autogen`. **Авторы:** Microsoft Research и сообщество. **Статус на дату просмотра:** архивирован Microsoft и не поддерживается как проект; сохранён для исторического использования. **Источник:** [репозиторий и README](https://github.com/microsoft/autogen), локальная версия README сохранена в [fulltext.md](fulltext.md).

## 1. Главный вопрос и ответ

AutoGen — программный фреймворк для приложений, где агенты LLM действуют автономно или вместе с человеком. Его ценность для исследования — готовые примитивы обмена сообщениями, runtime и orchestration patterns. Это платформа, а не статья о том, что агенты действительно спонтанно распределяют роли или создают нормы.

## 2. Что проверяли: вопросы и гипотезы

README не задаёт научных гипотез. Программный проект нацелен на создание agentic-приложений и многоагентных workflows. Исследовательские гипотезы должны формулироваться в отдельном эксперименте и не выводиться из наличия API группового чата.

## 3. Агенты, среда и исходные условия

Текущий README описывает Python AgentChat API, Core API и Extensions API; есть также .NET/runtime. Агент может подключать модельный клиент, инструменты, другой агент как tool или групповой чат. В quickstart используются облачные OpenAI модели; расширения поддерживают разные клиенты. Среду, идентичности, правила и интересы задаёт пользователь.

## 4. Метод и пошаговый пайплайн

Разработчик задаёт конфигурацию агента, модельный клиент, системное сообщение и инструменты. Агент запускается с задачей, обрабатывает ответы и может вызывать инструменты или подчинённых агентов до лимита итераций. AgentChat поддерживает распространённые шаблоны общения, Core реализует событийные агенты и локальный/распределённый runtime, Extensions связывает провайдеров и инструменты, AutoGen Studio позволяет прототипировать визуально. Система может также работать в потоковом асинхронном режиме.

## 5. Экспериментальный дизайн и метрики

Репозиторий сам не задаёт бенчмарк или метрики. В экосистеме есть AutoGen Bench как набор оценки agent performance, но README описывает прежде всего инфраструктуру. Для научного опыта нужно самостоятельно контролировать количество ходов, передачу сообщений, модель, бюджет вызовов, tool execution и stopping condition.

## 6. Основные результаты

Репозиторий демонстрирует программную возможность строить одиночные и составные системы, запускать MCP-инструменты и компоновать специализированных агентов. Важное обновление статуса: README сообщает, что проект архивирован и больше не поддерживается Microsoft; новым пользователям предлагается Microsoft Agent Framework, а существующим — миграция. Из этого следует учитывать отсутствие новых исправлений/безопасностных патчей и поддержку сообщества в ограниченном режиме.

## 7. Что из этого следует и чего не следует

AutoGen может помочь быстро сравнить разные протоколы взаимодействия, но его scheduling и orchestration сами являются факторами эксперимента. Использование group chat, агента-tool или supervisor задаёт структуру обмена; это не следует описывать как найденную естественную иерархию. Архивный статус делает его менее надёжным выбором для нового долгосрочного исследовательского стенда.

## 8. Ограничения и воспроизводимость

Проект archived, лишён регулярных новых функций и security updates; Microsoft не советует использовать его в production. README на ветке `main` может оставаться доступным историческим артефактом. Для воспроизводимости закрепить конкретную версию/commit, зависимости, модельный API и схемы сообщений. AutoGen Studio предназначен для прототипирования, не производственной эксплуатации. При сравнении библиотек следует фиксировать версии и не переносить эффект orchestration на поведение модели.

## 9. Значение для Лаборатории № 57 и «Верхума»

Для лаборатории полезны готовые шаблоны коммуникации как baseline, с которым можно сопоставить собственный симулятор и ручной сетевой граф. Вклад в теорию активных систем — тестировать управление через централизованную оркестрацию против локального peer-to-peer. Для книги можно исследовать, какие культурные эффекты исчезают, если роль супервизора задана оболочкой. Но для текущего прототипа стоит сравнить AutoGen как историческую основу с поддерживаемыми инструментами.
