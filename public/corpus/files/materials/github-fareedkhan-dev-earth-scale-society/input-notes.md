## Содержание и эмпирика

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 1178.

Репозиторий предоставляет сквозной notebook: ответы Qwen3-235B используются для обучения малой модели-посредника и предварительного заполнения таблицы переходов; затем моделируется сеть из миллиарда агентов, чьи профили основаны на World Values Survey. Автор сообщает о 900 млн ключей таблицы, 4,47-миллионной суррогатной модели и 100 раундах за 104 секунды после предвычисления. Включены конфигурации на 20 тыс., 1 млрд агентов и длительный 5-тысячный прогон; опубликована инструкция воспроизведения.

## Ограничения

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 1178.

Это самостоятельный инженерный проект, а не рецензируемое российское исследование. Во время социального прогона LLM не вызывается: работает стохастический автомат, выучивший переходы на ответах одной Qwen-модели. Агенты сводятся к 10 тыс. анкетным персонам; у них нет памяти и текстовых сообщений, а метрика точности сравнивает симулятор с исходной Qwen, не с реальной динамикой общества. WVS не включён в репозиторий и требует регистрации; полный этап обучения требует оборудования автора (в README указаны четыре H100).
