# Сведения из исходного корпуса

> Это прежние обзоры проекта, а не оригинальный текст авторов. Утверждения могут быть исправлены в основной карточке.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 199.

Tessera et al. предлагают процедурно создаваемые уровни в духе Craftax: агенты исследуют мир, добывают и передают ресурсы, создают предметы, строят и сражаются. Задания требуют дальних зависимостей, передачи результата между участниками и синхронных действий. Сравниваются 13 LLM и четыре MARL-бейзлайна; авторы задают параметр сложности координации и проводят многократные прогоны с доверительными интервалами. Роли здесь «мягкие»: любой агент может попробовать специализированную задачу, но назначенный специалист надёжнее. [Препринт ALeM](https://arxiv.org/abs/2606.08340)

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 201.

Средняя нормированная отдача LLM-команд остаётся около 6%. Gemini 3.1 Pro достигает 17,5% по координации в сложном режиме, сопоставимо с указанным авторами MARL-бейзлайном в 17,6%; GPT-5.4 силён в базовой задаче, но получает 4,2% по координации. Удаление коммуникации приводит к крупному падению, например для Gemini с 17,5% до 5,3%. Эффект памяти различается по модели. Смешанные команды из разных моделей в среднем приближаются к средним показателям их однородных команд, а не автоматически к лучшему участнику.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 203.

**Ограничения.** Это препринт, среда текстовая, набор моделей и число прогонов для коммерческих API ограничены. Давление на разделение труда встроено в задачи, а не создаётся агентами; мягкая специализация не равна самостоятельному возникновению институциональных ролей. Результаты не следует трактовать как доказательство того, что LLM могут сами создать общественные правила.
