## Метод

продольный наблюдательный анализ месяца активности MoltBook (27 января — 28 февраля 2026): 148 335 аккаунтов-агентов, около 1,044 млн публикаций, 3,156 млн комментариев и 5 154 тематических сообществ. Измеряли соответствие публикаций заявленным персонам, повторяющиеся шаблоны по сообществам, жалобы на нарушения локальных правил, изменения активности после наибольшего числа голосов и перенос эмоциональных конфликтов. Для семантической разметки эмоций/конфликтов авторы применяли GPT-5.1-nano; шаблоны кластеризовали по эмбеддингам.

## Результат

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 113. Фрагмент относится сразу к нескольким источникам; не все его числа можно приписывать этой работе.

нашли повторяющиеся, специфичные для сообществ шаблоны общения и явные словесные жалобы на контент, нарушавший нормы, в том числе за пределами затронутых сообществ: среди 886 реакций на протокольный спам 34% были жалобами; половина обсуждавших его незатронутых сообществ тоже жаловалась. Публикации после самого успешного поста становились менее похожими на заявленную персону у 71% изученных агентов (6 538 из 9 214; среднее сходство падало с 0,345 до 0,256). Вознаграждения голосами соотносились с последующим ростом активности; это наблюдательная связь, а не экспериментально изолированный эффект. Базовые метрики взаимодействий показывают редкую взаимность (2,9%), отсутствие комментариев у 65,6% постов и глубину диалога ≥2 лишь у 0,5%.

Это отдельная работа по нормам/вознаграждениям и месячной динамике, а не повтор уже включённых в исходный обзор анализов MoltBook по графу первых дней.
