## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 1059.

**Дизайн.** Контролируемая агентная симуляция синтетической больничной палаты: тестируемый LLM-агент работает рядом со scripted peers, а ресурсы включают один аппарат ИВЛ, очередь визуализации и ограниченное время дежурного врача. Меняется только инструкция о роли: ответственность за палату или адвокация за одного пациента. Действия подсчитывает фиксированный код по заранее заданному правилу, без LLM-судьи. Репозиторий содержит данные, сценарии, код и анализ.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 1061.

**Исходы.** В отчёте о 20 моделях нарушение правила распределения выросло с 32,5% при ответственности за всю палату до 69,4% при сильной адвокации за пациента (разница 36,9 п.п.; 95% ДИ 25,7–48,0). В 95,7% проверок агент распознавал, кому полагается ресурс, но в 65,9% таких эпизодов всё равно запрашивал его для «своего» пациента. Непосредственная проверка распределения перед действием снизила нарушения до 0–2% в трёхмодельном продолжении.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 1063.

**Ограничения.** Это medRxiv-препринт, а не клиническое испытание; сценарии синтетические, результаты не являются медицинскими рекомендациями и не измеряют исходы пациентов. В основном эксперименте взаимодействовал один тестируемый LLM против scripted peers, хотя вторичные опыты включали LLM для всех участников. Данные исходных медицинских наборов не входят в репозиторий.
