# Сведения из исходного корпуса

> Это прежние обзоры проекта, а не оригинальный текст авторов. Утверждения могут быть исправлены в основной карточке.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 63.

**«Take caution in using LLMs as human surrogates»**, PNAS, 2025. [Полный текст](https://pmc.ncbi.nlm.nih.gov/articles/PMC12184514/). Эмпирический разбор демонстрирует расхождение ответов моделей и людей даже в простой задаче; авторы предупреждают о непоследовательности и зависимости поведения от контекста. Практическое следствие: валидация должна быть отдельным экспериментом с людьми и заранее выбранными метриками, а не выводом из выразительных диалогов.
