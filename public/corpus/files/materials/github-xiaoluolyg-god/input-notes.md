## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 925. Фрагмент относится сразу к нескольким источникам; не все его числа можно приписывать этой работе.

[GitHub GOD](https://github.com/XiaoLuoLYG/GOD) — локальная панель управления для социальных симуляций; есть опубликованное описание в [EMNLP 2026 System Demonstrations](https://arxiv.org/abs/2608.27992). Панель позволяет просматривать живой и записанный прогон, перематывать шаги, задавать вопрос выбранному агенту, вмешиваться в следующий шаг и экспортировать пакеты сценария, карты и агентов. Интерфейс, сервер, состояние запуска и хранилище воспроизведения работают локально; модели подключаются через совместимый с OpenAI API адрес. Веб-реплеи и пакеты можно просматривать без настройки локальной среды.
