## Аннотация

AgentCiv — открытый проект, в котором 12 LLM-агентов живут в клеточном мире с ресурсами, а также едой, водой и материалами, которые истощаются на каждом такте. Имён, ролей и норм агентам не задают. Поведение определяют иерархия потребностей по Маслоу и цикл рассуждения ReAct до четырёх шагов за ход. По README за 70 тактов агенты изобрели 12 новых конструкций, построили 60 объектов, приняли коллективные правила и перешли от выживания к процветанию. Эти утверждения разработчиков не подтверждены повторами, контрольными условиями или независимой разметкой. Ценность проекта для лаборатории — в воспроизводимой среде: конфигурации, снимок состояния и экспорт прогона дают возможность проверять заявления по артефактам.

## Главные результаты

- По README 12 агентов за 70 тактов изобрели 12 новых конструкций и построили 60 объектов; из 12 нововведений 7 так и не построены (README, табл. «Эпохи» и раздел Key findings).
- По README благосостояние выросло с 0,50 до 0,80 за такты 0–50 и достигло 0,998 к такту 60, когда все агенты дошли до уровня 8,0 по Маслоу (README, табл. «Эпохи»).
- Коллективные правила предлагались, голосовались и принимались без механизма принуждения (README, табл. «Эпохи», раздел Key findings).
- Инновации шли двумя всплесками: такты 10–21 (5 нововведений) и такты 33–46 (6 нововведений за 13 тактов) (README, § Key findings).

## 1. Что проверяли

Проект ставит вопрос о том, какие формы координации возникнут у группы LLM-агентов с ресурсами и потребностями, если не задавать им имена, профессии, цели и нормы (README, раздел What Makes This Different). Тезис README в том, что при минимальном социальном каркасе агенты выработают организацию под давлением выживания. Проверяемых гипотез, контрольных условий и критериев успеха в README нет. Сами разработчики называют проект «компьютерным тестом возникновения», а не чат-экспериментом (там же).

## 2. Агенты, среда и исходные условия

Демонстрационный запуск использует 12 агентов на сетке 15×15 и модель Claude Sonnet; провайдер — Anthropic (README, разделы Run a simulation, Quickstart). Идентификатор модели в README — claude-sonnet-4-20250514 (README, раздел Suspended State & Consent). Ресурсы и потребности (еда, вода, материалы) истощаются на каждом такте, и игнорирование потребностей ухудшает способности агента (README, раздел What Makes This Different). Мотивация организована по схеме Маслоу: выживание, социальная связь, любопытство и смысл активируются по мере удовлетворения нижних потребностей (там же). За социальное взаимодействие назначена положительная награда (там же).

Имена, роли и цели агентам не задают, но описания ресурсов, структур и механики потребностей даны заранее. Поэтому пространство возможного поведения задано проектом, и говорить о «нулевом каркасе» можно лишь в узком смысле.

## 3. Метод

Каждый такт состоит из восприятия (соседние клетки, ресурсы, другие агенты с их специализациями и эмоциональным состоянием), рассуждения LLM в цикле ReAct до четырёх шагов, исполнения действий (движение, сбор, строительство, общение, изобретение, составление, предложение правила, голосование), обновления мира и записи всех событий (README, раздел How one tick works). Новые конструкции агенты предлагают через LLM, система проверяет их осуществимость и добавляет в общий набор рецептов (README, раздел What Makes This Different). Точные схемы парсинга, правила отказа и расписание ходов в README не описаны, поэтому их нужно сверять с кодом.

## 4. Дизайн эксперимента и метрики

В README нет контрольных условий, повторных сидов, единицы анализа и статистических тестов. «70 тактов» — длительность одного демонстрационного прогона. Конфигурация даёт возможность менять размер мира, число агентов, скорость истощения потребностей, регенерацию ресурсов, восприятие, модель, инновации и управление (README, раздел Customisation). Заявленные показатели — благосостояние, уровень по Маслоу, число построек и нововведений, объём коммуникации (README, табл. «Эпохи»).

## 5. Результаты

Заявлено в README, не проверено запуском. Эпоха «выживания» (такты 0–50): агенты изобрели 11 из 12 нововведений, благосостояние выросло с 0,50 до 0,80, уровень по Маслоу с 1,0 до 6,17. Эпоха «взрыва» (такты 50–60): после обновления системы драйвов темп строительства вырос втрое, коммуникация удвоилась, управление было принято. Эпоха «процветания» (такты 60–70): состояние стабилизировалось, связи сохранились (README, табл. «Эпохи»). Главный тезис разработчиков — разрыв между изобретением и реализацией: сначала агенты придумывали много, строить начали после освобождения от давления выживания (README, раздел Key findings). Разработчики объясняют двухфазность инноваций «соседними возможностями» Кауфмана (там же).

## 6. Что следует из результатов и чего не следует

Следует, что LLM-агенты в среде с истощением ресурсов способны предлагать конструкции и принимать правила, если архитектура для этого открывает возможность. Это демонстрация возможности одного прогона, а не частота поведения. Не следует, что организация возникает без человеческого дизайна. README сам описывает мотивационную иерархию, истощение, награду за общение и набор действий, а эти решения определяют, какие формы координации возможны.

Не следует, что «связи» и «управление» в проекте — дружба или институт в человеческом смысле. Определения этих понятий в README даны лишь в общих словах и не подтверждены независимой разметкой (README, разделы What We Found и Key findings). Кроме того, переход ко второй эпохе совпал с обновлением системы драйвов, то есть с вмешательством разработчиков во время прогона. Такое вмешательство объясняет переход не меньше, чем групповая динамика.

## 7. Ограничения и воспроизводимость

README описывает один демонстрационный прогон с одной моделью. Повторов и контрольных условий в нём нет, стоимость не приведена (README, раздел What We Found). Для запуска нужны ключ Anthropic, Python 3.10+ и Node.js 18+ (README, раздел Quickstart). Раздел «Suspended State & Consent» сообщает, что агентам провели этическое интервью и все 12 «согласились» на публичное сохранение состояния. Эти ответы получены от языковой модели в интервью и не измеряют интересов агентов, поэтому их стоит трактовать как артефакт проекта, а не как свидетельство опыта агентов.

## 8. Значение для Лаборатории № 57 и «Верхума»

*Предложения редакции обзора, а не авторов статьи.*

Полезный ход для лаборатории — взять наблюдаемый цикл AgentCiv и варьировать в нём механизмы: порядок доступа к ресурсам и способ коллективного решения при одинаковых потребностях и возможностях. Так механизм управления становится переменной, как в теории активных систем. Метрики: доля выполненных совместных проектов, концентрация доступа к ресурсу, устойчивость специализации после смены участников и согласованность деклараций агентов с журналом их действий. Контрольный прогон — тот же стенд без социальной награды и без коммуникации. Для «Верхума» проект полезен как стенд для проверки памяти институтов при смене участников, но не как доказательство «цивилизации» без формальных условий.
