# Сведения из исходного корпуса

> Это прежние обзоры проекта, а не оригинальный текст авторов. Утверждения могут быть исправлены в основной карточке.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 75.

**MoltBook Entropy Collapse Experiments — GLM-5**, набор данных на Hugging Face. [Карточка и файлы](https://huggingface.co/datasets/Ayushnangia/moltbook-entropy-collapse-glm-5). По описанию авторов, собраны логи шести условий с десятью агентами OpenClaw/Moltbot, моделью GLM-5 через OpenRouter, часовыми прогонами и различным начальным содержимым; указано 1641 пост и 2646 комментариев. Это близко к желаемому стенду и ценно тем, что предоставляет данные, а не только пересказ. Набор пока не проверен повторным анализом; подтверждать «схлопывание разнообразия» без анализа логов нельзя. На момент просмотра встроенный просмотрщик сообщает об ошибке схемы; файлы следует читать отдельно.
