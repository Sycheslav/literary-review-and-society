# Сведения из исходного корпуса

> Это прежние обзоры проекта, а не оригинальный текст авторов. Утверждения могут быть исправлены в основной карточке.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 903. Фрагмент относится сразу к нескольким источникам; не все его числа можно приписывать этой работе.

У [YuLan-OneSim](https://github.com/RUC-GSAI/YuLan-OneSim) есть [статья](https://arxiv.org/abs/2505.07581), [документация](https://ruc-gsai.github.io/YuLan-OneSim/) и Docker-сценарий развёртывания. Код позволяет описывать сценарий на естественном языке, строить среду и запускать социальную симуляцию; авторы перечисляют 50+ готовых сценариев по восьми областям социальных наук. Работа опубликована в воркшопе NeurIPS 2025 по средам масштабирования агентов, а не в основном треке конференции.
