## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 925.

[GitHub GOD](https://github.com/XiaoLuoLYG/GOD) — локальная панель управления для социальных симуляций; есть опубликованное описание в [EMNLP 2026 System Demonstrations](https://arxiv.org/abs/2608.27992). Панель позволяет просматривать живой и записанный прогон, перематывать шаги, задавать вопрос выбранному агенту, вмешиваться в следующий шаг и экспортировать пакеты сценария, карты и агентов. Интерфейс, сервер, состояние запуска и хранилище воспроизведения работают локально; модели подключаются через совместимый с OpenAI API адрес. Веб-реплеи и пакеты можно просматривать без настройки локальной среды.

## note

Источник: `исходники исследований лит обзор/Дополнительный обзор социумов ИИ-агентов.md`, строка 927.

Авторы оценивали интерфейс на 15 завершённых слотах запуска. В 14 прогонах с вмешательствами 78 из 84 проверок целевого агента фиксировали заданное место, а 169 из 182 ответов о состоянии совпадали с сохранённым местом или действием. Это измеряет работу интерфейса и следа воспроизведения, не качество социального поведения. Проект собирает компоненты AgentSociety и JiuwenClaw, поэтому я рассматриваю его как **полезный слой наблюдаемости и обмена экспериментами**, а не как отдельный научный результат о больших обществах. Авторы в README также прямо отделяют инспекцию общества от утверждения о его социальной реалистичности.
