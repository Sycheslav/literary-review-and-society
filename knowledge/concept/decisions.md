# 21. Открытые решения для обсуждения

Рабочий обзор для обсуждения. Аннотации и переводы требуют сверки с первоисточником перед цитированием. Предложения проекта не являются результатами проведённых экспериментов.

[К индексу](../index.md) · [Страница сайта](https://literature-review.up.railway.app/concept/decisions)

**Социальная организация ИИ-агентов, коллективное решение задач и экспериментальная программа Лаборатории № 57 «Активных систем» ИПУ РАН**

**Версия:** 1.2 · 31 октября 2026 года.  
**Статус:** рабочая основа для обсуждения с коллегами. Лаборатория ещё не утверждала ни эксперименты, ни бюджет, ни состав команды, ни архитектуру стенда.

Здесь собраны замысел проекта, рабочие понятия, правила методологии, идеи экспериментов и план. Пересказы публикаций находятся в литературном графе и карточках работ.

| Решение | Отправная точка | Что нужно выяснить |
| --- | --- | --- |
| Первый научный вопрос | Механизм с частной информацией или информационная игра | Какая постановка ближе к текущей работе коллег |
| Прикладной сценарий | Повторяющийся прогноз с внешней проверкой | Данные, горизонт, базовый алгоритм, задержка факта |
| Первая популяция | Небольшая однородная группа, затем около двадцати участников | Минимальный размер, при котором вопрос сохраняет смысл |
| Конфликт интересов | Явные различия частных выгод и информации | Понимает ли их модель |
| Экономика | Простые счета, выплаты и ограниченный доступ к данным | Нужно ли в первом опыте отключение агентов |
| Объединения | Неформальная кооперация, затем регистрация с ограниченными правами | Какие права действительно нужны |
| Память | Раздельные предметные и социальные записи с общим журналом | Как ограничивать контекст и чисто вмешиваться |
| Оболочка | Минимальный агент с наблюдаемыми действиями | Что дают готовые системы |
| Модель | По измеренному пилоту, а не только по цене токена | Понимание правил, валидность, стоимость |
| Критерий эффекта | Одна основная метрика и профиль побочных исходов | Какой размер улучшения важен |
| Участие людей | Отдельная последующая серия | Есть ли организаторы, выборка и подходящая деловая игра |

Решение записывается по схеме: вопрос → выбранный вариант → основание → ответственный → дата → условия пересмотра. Тарифы, версии моделей и результаты запусков обновляются в своих карточках, а в концепцию попадают только решения, меняющие замысел.
