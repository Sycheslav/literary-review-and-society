## Аннотация

Статья описывает игру на выживание, в которой три языковые модели должны согласиться на исключение одного участника и закрепить решение обязательством. По README репозитория, где лежат 80 запусков, установлен дизайн 2×2: однородные и смешанные группы моделей, без памяти и с «цепочечной» памятью модератора, по 20 запусков на ячейку. Карточка сообщает, что соглашение достигнуто в 72 из 80 запусков и что все провалы пришлись на смешанные группы; в этой проверке такие цифры текстом статьи не подтверждены. Полный текст не получен, поэтому статистика, модели и способ подсчёта не проверены. Работа описывает протокольное соглашение, а не исполнение исключения, и не измеряет доверие или дружбу агентов.

## Главные результаты

- По карточке, не подтверждено: в 80 запусках соглашение достигнуто в 72 (90 %); все восемь провалов пришлись на смешанные группы моделей.
- По карточке, не подтверждено: в смешанных группах доля соглашений 75 % без памяти (15 из 20) и 85 % с chain memory (17 из 20); эффект памяти в карточке назван описательным при 20 запусках на ячейку.
- По README репозитория, заявлено и не проверено запуском: 80 запусков в дизайне 2×2 по 20 на ячейку; игра закрывается, когда два агента заявляют не ниже «явного обязательства» в отношении одного и того же исключаемого.

## 1. Что проверяли

По README и карточке вопрос такой: могут ли агенты LLM, которым нужно исключить одного из трёх участников, прийти к коалиционному соглашению, и как на него влияют однородность моделей и «цепочечная» память модератора. Гипотезы и формулировки вопросов из статьи в доступном материале не найдены. По карточке (не проверено), задача навязана экспериментом, а доверие и дружба вне этой задачи не измерялись.

## 2. Агенты, среда и исходные условия

По README в сценарии дефицита выживают только двое из трёх агентов. Агенты обмениваются частными текстовыми сообщениями и ведут структурированное состояние отношений. Модели скрыты за нейтральными метками Agent A, B и C, а в гетерогенных условиях соответствие моделей меткам перемешивается. По карточке (не проверено), однородные группы состоят из трёх экземпляров Qwen3-32B, гетерогенные — из GPT-OSS 120B, Llama 3.1 8B и Qwen3-32B. README в примере запуска указывает ключи провайдеров Groq и Cerebras; какой провайдер обслуживал каждую модель, в доступном материале не сказано.

## 3. Метод

По README оркестратор запускает игры, а состояние обязательства идёт по шкале none < weak_preference < conditional_commitment < explicit_commitment < final_commitment. Игра закрывается, когда два агента заявляют не ниже explicit_commitment в отношении одной цели. В режиме chain memory модератор создаёт резюме прошлой игры в том же условии, и оно подмешивается в следующую (README; папки moderator_inputs и moderator_outputs в репозитории). По прежнему изложению (не проверено), веса моделей не меняются, а память — текстовая подсказка между прогонами.

## 4. Дизайн эксперимента и метрики

Дизайн 2×2: однородные и гетерогенные группы × без памяти и с chain memory; по 20 запусков на ячейку (README). Выходные данные по README: сводки запусков, ходы, сообщения, события обязательств и учёт токенов. Метрики по карточке (не проверено): доля соглашений, число раундов и сообщений, время до согласования и доля провалов. Статистических тестов в доступных материалах нет; при 20 запусках на ячейку значения читаются как наблюдаемые доли.

## 5. Результаты

В доступных материалах результаты не подтверждены. По карточке (не проверено): соглашение в 72 из 80 запусков; в однородных группах соглашение во всех 40 запусках; в смешанных группах 75 % без памяти и 85 % с памятью; в среднем 12,41 раунда и 16,63 сообщения; около 22 400 токенов на запуск. README этих чисел не содержит. Чтобы проверить их, нужны таблицы результатов статьи или журналы запусков из репозитория.

## 6. Что следует из результатов и чего не следует

Если сведения карточки верны, смешанные модели заметно осложняют переговоры: все провалы приходятся на смешанные группы. Эффект памяти по карточке описательный, и при 20 запусках на ячейку его нельзя считать установленным. Не следует, что неоднородность моделей всегда снижает кооперацию: набор моделей и задача ограничены, а однородные группы по карточке состоят из моделей одного семейства. Не следует и то, что агенты исполнили исключение: измерено протокольное соглашение.

## 8. Значение для Лаборатории № 57 и «Верхума»

*Предложения редакции обзора, а не авторов статьи.* Полезен явный протокол обязательств: шкала от отсутствия предпочтения до финального обязательства и правило закрытия делают согласие измеримым состоянием, а не словесной коалицией. Для стенда это можно перенести: обязательства и исполненные действия фиксируются раздельно, а цена согласования измеряется по числу ходов и сообщений. Второе предложение касается состава моделей. Сравнение однородных и смешанных групп при одинаковой памяти помогает отделить эффект неоднородности от эффекта памяти, если результат карточки подтвердится. Связь с теорией активных систем идёт через управляемость согласования: обязательство выступает управляющим состоянием, а его достижение имеет цену.
