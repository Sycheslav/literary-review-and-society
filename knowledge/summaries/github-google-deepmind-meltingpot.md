# Melting Pot: набор сред для проверки социальной компетентности агентов

**Оригинальное название:** *Melting Pot: A suite of test scenarios for multi-agent reinforcement learning* (заголовок README); базовая статья — *Scalable Evaluation of Multi-Agent Reinforcement Learning with Melting Pot*  
**Авторы и год:** DeepMind contributors (репозиторий); базовая статья: Joel Z. Leibo, Edgar Duéñez-Guzmán, Alexander Sasha Vezhnevets, John P. Agapiou, Peter Sunehag, Raphael Koster, Jayd Matyas, Charles Beattie, Igor Mordatch, Thore Graepel (по BibTeX из README); 2021.  
**Тип и статус:** программный пакет и открытый benchmark (репозиторий Google DeepMind). Лицензия в прочитанном README не найдена; карточка называет Apache-2.0, по README это не подтверждено.  
**Оригинал:** [репозиторий GitHub](https://github.com/google-deepmind/meltingpot); [Melting Pot 2.0 Tech Report, arXiv:2211.13746](https://arxiv.org/abs/2211.13746).  
**Прочитанный источник:** README проекта, локальная копия [readme-source.md](https://github.com/google-deepmind/meltingpot), снимок ветки main от 29.10.2026. Статьи не читались. Это описание проекта, а не изложение статьи.

## Аннотация

Вопрос проекта: как проверить, переносят ли многоагентные агенты обучения с подкреплением свою социальную компетентность на новых партнёров и новые ситуации. Пакет Melting Pot предлагает более 50 многоагентных игр (substrates), на которых агентов обучают, и более 256 отложенных тестовых сценариев, где их оценивают, в том числе с незнакомыми участниками. Итоговый балл предназначен для ранжирования алгоритмов по обобщению. Оговорка: README не содержит новых экспериментальных результатов, формул баллов, числа сидов и доверительных интервалов, а языковые модели в пакете не рассматриваются. Балл измеряет поведение в заданных играх с заданными правилами и наградами, а не эмпатию или дружбу.

## Главные результаты

- Пакет содержит более 50 многоагентных сред (substrates) и более 256 отложенных тестовых сценариев (README, §About).
- Тесты проверяют кооперацию, конкуренцию, обман, взаимность, доверие и упрямство, а также взаимодействие с незнакомыми участниками (README, §About).
- Оценка обученных политик выполняется библиотекой evaluation, которая принимает модели в формате SavedModel (README, §Example usage).
- Результаты технического отчёта 2.0 вынесены в ноутбук evaluation_results. Сами числа в README не приведены (README, §Example usage).
- Установка через PyPI командой `pip install dm-meltingpot`. Пакет построен на DeepMind Lab2D; при отсутствии готового колеса dmlab2d его собирают из исходников (README, §Installation).

## 1. Что проверяли

Melting Pot проверяет обобщение на новые социальные ситуации, в которых участвуют и знакомые, и незнакомые индивиды (README, §About). Вопрос сформулирован так: способны ли агенты, обученные на определённых партнёрах, переносить свою компетентность на новых партнёров и сценарии (README, §About). Это инструмент и набор тестов, а не статья с гипотезой. README не формулирует проверяемых гипотез и не описывает эффект, который следует ожидать. Смысл проекта в том, чтобы проверять обобщение, а не только результат в знакомой среде (README, §About).

## 2. Агенты, среда и исходные условия

Substrate — многоагентная игра с пространством, правилами и ресурсами. Тестовый сценарий задаёт социальную ситуацию и участников (README, §About; подробности в документации). Агенты обучаются на substrate, затем проходят отложенные сценарии, часть которых включает незнакомых участников (README, §About). Пакет построен на DeepMind Lab2D (README, §Installation). README не упоминает языковые модели, LLM-агентов или естественно-языковое общение. Исходный фокус проекта — обучение политик с подкреплением (README, §About, §Example usage).

## 3. Метод

Исследователь устанавливает пакет через pip, выбирает substrate и обучает на нём политику. Затем библиотека evaluation оценивает сохранённую модель и выдаёт балл по отложенным сценариям (README, §Installation, §Example usage). Для знакомства с играми есть скрипты human_players, например play_clean_up.py, с управлением клавишами W, A, S, D, Q, E, 1, 2 и TAB (README, §Example usage). Для разработки README рекомендует Codespace или редактируемую установку с проверкой через pytest (README, §Development).

## 4. Дизайн эксперимента и метрики

Единица оценки — тестовый сценарий. Итоговый балл используется для сравнения алгоритмов RL по обобщению на новые социальные ситуации (README, §About). README не раскрывает формулу балла, число сидов, доверительные интервалы и процедуру агрегации (заявлено в README, не проверено запуском). Для сравнения методов разумно фиксировать набор сценариев, версию среды, алгоритм, число независимых обучений и правила агрегации. Это рекомендация редакции, а не требование README.

## 5. Результаты

README не приводит новых экспериментальных результатов. Он заявляет каталог более 50 сред и более 256 тестовых сценариев, а также инфраструктуру оценки (заявлено в README, не проверено запуском; README, §About). Результаты технического отчёта 2.0 показаны в ноутбуке evaluation_results. Сами числа в README не приведены, а ноутбук и отчёт не открывались (README, §Example usage). Фраза о том, что проект станет стандартным benchmark, выражает пожелание авторов: «We hope» (README, §About).

## 6. Что следует из результатов и чего не следует

Из описания следует, что проект задаёт один протокол для проверки переноса на новых партнёров и ситуации, но не даёт единого числа «социального интеллекта» (README, §About). Не следует, что высокий балл означает эмпатию, дружбу или универсальную кооперативность. Балл измеряет поведение в заданных играх с заданными правилами и наградами (README, §About; оценка редакции).

## 7. Ограничения и воспроизводимость

README ссылается на ветку main, которая может меняться. Для исследования нужны фиксированный commit и версия пакета (README, §Installation). Пакет зависит от DeepMind Lab2D, и её сборка может потребовать ручных шагов (README, §Installation). README прямо указывает, что Google официально проект не поддерживает (README, §Disclaimer). Языковых моделей и естественно-языкового канала в README нет, поэтому перенос на LLM-агентов требует интеграции и отдельной проверки интерфейса (оценка редакции). Лицензия в прочитанном тексте не указана. Карточка называет Apache-2.0, это нужно проверить по файлу LICENSE в репозитории.

## 8. Значение для Лаборатории № 57 и «Верхума»

*Предложения редакции обзора, а не авторов статьи.*

Первый механизм — структура «обучение на одном составе, проверка с новыми партнёрами». Агентов настраивают без конкретного партнёра, затем проверяют на новых условиях обмена и коллективного выбора. Второй механизм — менять в игре правило распределения ресурса или наблюдаемость действий и измерять перенос кооперации и манипуляции между составами. Такой контроль механизма дополняет оценку локального успеха и социальной компетентности. Связь с теорией активных систем состоит в управлении механизмом при несовпадающих интересах участников. В README этой связи нет.
