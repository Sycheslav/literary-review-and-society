# Melting Pot: набор сред для проверки социальной компетентности агентов

**Оригинальное название:** Melting Pot: A Suite of Test Scenarios for Multi-Agent Reinforcement Learning. **Авторы:** DeepMind contributors; научная статья — Leibo et al., 2021. **Тип:** открытый benchmark и программный пакет для многоагентного обучения с подкреплением. [Репозиторий](https://github.com/google-deepmind/meltingpot); [технический отчёт Melting Pot 2.0](https://arxiv.org/abs/2211.13746). Прочитан README; это описание проекта, не подробное изложение статьи.

## 1. Главный вопрос и ответ

Melting Pot предназначен для оценки обобщения в незнакомых социальных ситуациях: способны ли агенты, обученные взаимодействовать с определёнными людьми/политиками, переносить компетентность на новых партнёров и сценарии, которые не встречались при обучении. README описывает более 50 многоагентных «substrates» (игр/сред) и более 256 уникальных тестовых сценариев. Итоговые баллы на отложенных ситуациях предназначены для сравнения алгоритмов RL по их способности действовать в условиях взаимозависимости.

## 2. Вопросы и гипотезы

Это benchmark, а не статья с единой гипотезой. Его методологический тезис: оценивать социальную компетентность только в знакомой среде недостаточно; нужны новые сочетания людей и социальных обстоятельств. Сценарии охватывают кооперацию, конкуренцию, обман, взаимность, доверие и упрямство. Это заданные исследователями типы среды, а не самопроизвольное возникновение норм.

## 3. Агенты и миры

Пакет строится на DeepMind Lab2D. Substrate представляет повторно запускаемую многоагентную игру с пространством, правилами и ресурсами; test scenario задаёт конкретную социальную ситуацию и участников. Обученные агенты оцениваются на held-out сценариях с знакомыми и незнакомыми индивидуумами. README не ориентирует benchmark непосредственно на LLM или языковое общение: исходный фокус — RL политики и социальное обобщение. Поэтому перенос на текстовых агентов потребует адаптации интерфейса наблюдений/действий и отдельной проверки, что языковой канал не меняет саму задачу.

## 4. Пайплайн использования

Исследователь выбирает substrate, обучает агентную политику на определённых сценариях, затем запускает официальный evaluation на отложенных тестовых ситуациях и агрегирует score. Репозиторий содержит код сред, инструменты оценки, примеры, инструкции установки и материалы по расширению. Сценарии создаются как тесты переноса, а не как открытая языковая среда с неограниченными действиями; точную тренировочную и тестовую разбивку и правила скоринга нужно брать из технического отчёта и конкретной конфигурации.

## 5. Дизайн и метрики

Тестовые сценарии — центральная единица анализа; score служит для сравнения методов RL. README сам по себе не раскрывает формулы каждого score, число seed, доверительные интервалы или статистические процедуры. Они зависят от substrate и версии пакета. Для корректного сравнения надо фиксировать набор сценариев, версии среды, алгоритм обучения, число независимых обучений и правила агрегации.

## 6. Результаты

README подтверждает, что проект предлагает масштабный каталог тестовых сценариев и исполняемую инфраструктуру. Он не заявляет в самом описании конкретную новую эмпирическую победу алгоритма; научные выводы следует брать из первичных статей. Ценность проекта — в возможности одинаково испытывать перенос между партнёрами и ситуациями, а не в одном обобщённом числе «социального интеллекта».

## 7. Что следует и чего не следует

Результат на знакомой обучающей среде и результат в отложенной социальной ситуации отвечают на разные вопросы. Melting Pot даёт полезный принцип оценки обобщения и контролируемого изменения партнёров. Однако высокий benchmark score не равен эмпатии, дружбе или универсальной кооперативности; поведение ограничено заданными правилами и reward-структурой.

## 8. Ограничения и воспроизводимость

Зависимости включают Lab2D и совместимое окружение; для некоторых платформ может понадобиться сборка пакета. Текущий README — плавающая ветка main, поэтому для исследования нужно записать commit и версию среды. Языковые LLM-агенты не являются объектом README; использование API-моделей и естественного языка не следует считать поддержанным по умолчанию.

## 9. Значение для Лаборатории № 57 и «Верхума»

Лаборатории можно перенести структуру «обучение на одном составе — оценка с новыми партнёрами» в компактную LLM-игру: агенты обучаются/настраиваются без конкретного партнёра, затем проходят новые условия обмена и коллективного выбора. Механизмный вариант — изменять правило распределения ресурса или наблюдаемость действий, оценивая перенос кооперации и стратегической манипуляции. Это может дополнить ТАС контролем механизма и дать операциональное различение локального успеха и социальной компетентности.
