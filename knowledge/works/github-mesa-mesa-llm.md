## Аннотация

Открытая библиотека Mesa-LLM, которая подключает LLM как агентов принятия решений к фреймворку агентного моделирования Mesa.

## Главные результаты

- README описывает Mesa-LLM как интеграцию LLM-агентов в фреймворк агентного моделирования Mesa для сценариев коммуникации, переговоров и решений на естественном языке.
- В README перечислены провайдеры: OpenAI, Anthropic, xAI, Hugging Face, Ollama, OpenRouter, Novita AI и Google Gemini.
- README прямо предупреждает, что репозиторий находится в активной разработке, а API может существенно измениться; это ограничивает воспроизводимость экспериментов поверх него.
- Данные о числе агентов, моделях в экспериментах, памяти, расписании и результатах в README не приводятся; такие сведения не заполнены и требуют отдельного изучения кода и документации.

## Как устроено исследование

Из README следует только общая рамка: Mesa-LLM задуман как способ использовать LLM в качестве агентов принятия решений внутри агентного моделирования Mesa. Заявлены сценарии, в которых поведение задаётся естественным языком, включая коммуникацию, переговоры и принятие решений под влиянием языковых инструкций. Среда, структура сетки или графа, число агентов, порядок активации, правила взаимодействия, сценарии по умолчанию и эксперименты в README не описаны. Поэтому дизайн экспериментов, который можно было бы сопоставить с задачами лаборатории, по этому источнику восстановить нельзя. Для таких деталей нужна документация Read the Docs (Getting Started) и исходный код, которые по ссылкам в README не входят в проверенный текст карточки.

## Техническая реализация

Установка через pip (пакет mesa-llm; для предрелизных версий опция --pre; также установка из git в режиме редактируемого пакета). Поддерживаемые провайдеры LLM по README: OpenAI, Anthropic, xAI, Hugging Face, Ollama, OpenRouter, Novita AI и Google Gemini. Таким образом, на одном стенде теоретически доступны и облачные API, и локальные модели через Ollama, и маршрутизатор OpenRouter, который интересен для дешёвых моделей. Конкретные идентификаторы моделей, способ выбора провайдера, управление памятью агентов, механизм коммуникации, расписание и хранение состояния в README не описаны. Версия библиотеки не зафиксирована, поскольку README предупреждает о возможных изменениях API. Сведения о CI (GitHub Actions), покрытии тестами (Codecov), линтинге (Ruff) и сборке (Hatch) относятся к инженерной инфраструктуре и не влияют на научные выводы.
