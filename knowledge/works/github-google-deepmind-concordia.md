## Аннотация

Открытая библиотека Google DeepMind для построения генеративных агентных симуляций, в которой Game Master (GM) разрешает действия агентов в языковой среде.

## Главные результаты

- Concordia описана в README как библиотека для построения и запуска генеративных агентных моделей; сущности (entities) действуют на естественном языке, а Game Master переводит их намерения в исходы.
- Архитектура состоит из сущностей, компонентов (инструкции, память, выбор действия), префабов (шаблонов), движка run_loop и интерфейсов среды (пошаговая, одновременная или асинхронная).
- Из README: независимость от модели (model-agnostic); нужны API LLM и провайдер эмбеддингов для ассоциативной памяти. Качество результатов зависит от выбранной модели.
- Пример в README: четыре друга в заваленном снегом пабе, спор из-за разбитой машины; агенты рассуждают по схеме March and Olsen (2011) из трёх вопросов: о ситуации, о себе и о том, что делает такой человек в такой ситуации.

## Как устроено исследование

Concordia моделирует среду через Game Master (GM): эта сущность симулирует мир, в котором взаимодействуют игроки (player entities). Игроки описывают намерения на естественном языке, а GM переводит их в исходы, проверяя, например, физическую правдоподобность в симулированном мире. Роли назначаются на каждый вызов run_loop: движок запрашивает действия у игроков и наблюдения у GM. Среда может быть устроена по-разному: в каталоге concordia/environment перечислены движки, которые определяют очерёдность ходов, одновременные или асинхронные действия. В README не приведены конкретные сценарии исследований, число участников по умолчанию, протокол измерения исходов и контрольные условия. Пример с четырьмя друзьями в пабе (ссылка на учебный материал в Colab) показывает агентов, которые используют схему трёх вопросов о ситуации, о собственной личности и о нормативном поведении. Этот пример иллюстративный; результаты в README не приводятся.

## Техническая реализация

Установка из PyPI (gdm-concordia) или в режиме разработки (pip install --editable .[dev]); тесты запускаются через pytest. Для LLM нужен API, поддерживающий выборку текста; дополнительно для ассоциативной памяти нужен текстовый эмбеддер фиксированной размерности. Компоненты: память (ассоциативная), сенсорные модули, инструкции, выбор действия; префабы — предсобранные конфигурации сущностей, которые переопределяются параметрами имени, инструкций и цели. Каталоги: concordia/prefabs, concordia/components, concordia/environment (интерфейсы движка), concordia/document (управление промптами и контекстом), concordia/language_model (обёртки API), examples/. Есть GUI и CLI для редактирования симуляции (ссылка на руководство по сущностям и компонентам). В README упоминаются дополнительные зависимости для провайдеров Google (pip install .[google]). Версия библиотеки и конкретные модели по умолчанию в README не указаны; их следует сверять с релизами в репозитории.

## Ограничения и интерпретация

Библиотека зависит от качества LLM и эмбеддера; README прямо предупреждает, что результаты зависят от модели. Социальные нормы, роли и институты не задаются готовым образом: их нужно моделировать компонентами и промптами. Не является официальным продуктом Google (дисклеймер). Для проверки свойств социума требуется собственная метрика и контрольные условия, которых README не предоставляет.
