## Аннотация

Открытый наблюдательный проект (observational project) об агентах в деревне Minecraft, заявляющий анализ появления практик и институтов без их заранее прописанного ввода.

## Главные результаты

- Репозиторий содержит код/конфигурации, перечисленные в README.
- Назначение — поддержка запуска или анализа связанной работы; отдельный эксперимент в этом репозитории не выделен.
- Наблюдения и утверждения (claims) должны быть привязаны к конкретным логам и вычислениям в VERIFICATION.md.
- Рекламные формулировки README не считаются результатом сами по себе.

## Как устроено исследование

Не путать свободное наблюдение траектории с причинной оценкой «возникновения института»: необходимо читать REPORT и VERIFICATION и таблицу соответствия утверждений данным. Код и данные предназначены для повторного просмотра конкретных событий и снимков.
