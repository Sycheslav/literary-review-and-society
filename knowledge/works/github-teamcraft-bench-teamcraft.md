## Аннотация

Официальный код, Docker-образ, датасет и чекпойнты VLA-моделей бенчмарка TeamCraft для мультимодальных командных систем в Minecraft.

## Главные результаты

- README ссылается на arXiv:2412.05255 и указывает Docker-образ, датасет и чекпойнты с централизованной и децентрализованной архитектурой (centralized/decentralized checkpoint).
