## Аннотация

Melting Pot — пакет из более 50 многоагентных игр и более 256 отложенных тестов для проверки обобщения RL-агентов на новых партнёров; README результатов не приводит, языковые модели не рассматривает.

## Главные результаты

- Пакет содержит более 50 многоагентных сред (substrates) и более 256 отложенных тестовых сценариев (README, §About).
- Тесты проверяют кооперацию, конкуренцию, обман, взаимность, доверие и упрямство, а также взаимодействие с незнакомыми участниками (README, §About).
- Оценка обученных политик выполняется библиотекой evaluation, которая принимает модели в формате SavedModel (README, §Example usage).
- Результаты технического отчёта 2.0 вынесены в ноутбук evaluation_results. Сами числа в README не приведены (README, §Example usage).
- Установка через PyPI командой `pip install dm-meltingpot`. Пакет построен на DeepMind Lab2D; при отсутствии готового колеса dmlab2d его собирают из исходников (README, §Installation).

## Как устроено исследование

Содержит повторяющиеся социальные дилеммы, распределение ресурсов, координацию и режимы взаимодействия; агенты получают вознаграждение (reward) в формальных средах. Разработано для бенчмарка обучения с подкреплением (RL benchmark), поэтому использование с LLM требует интеграции и отдельной проверки интерфейса и действий (actions).

## Результаты подробно

Даёт стандартизированные наборы задач и базовые варианты для социальных игр, но сам репозиторий не подтверждает результатов LLM.

## Выводы авторов

Melting Pot — набор из 50+ многоагентных сред и сценариев социальных дилемм для оценки обобщения во взаимодействиях с новыми партнёрами. Это не LLM-ориентированный набор, но может служить базовым вариантом MARL или средой для адаптера.

## Ограничения и интерпретация

Результаты MARL нельзя выдавать за результаты LLM; правила и вознаграждения бенчмарка специфичны.
