## Аннотация

Melting Pot — набор из 50+ многоагентных сред и сценариев социальных дилемм для оценки обобщения (generalization) во взаимодействиях с новыми партнёрами.

## Главные результаты

- Репозиторий содержит код и конфигурации, перечисленные в README.
- Назначение — поддержка запуска или анализа связанной работы; отдельный эксперимент в этом репозитории не выделен.
- Даёт стандартизированные наборы задач (task suites) и базовые варианты (baseline) для социальных игр, но сам репозиторий не подтверждает результатов LLM.

## Как устроено исследование

Содержит повторяющиеся социальные дилеммы, распределение ресурсов, координацию и режимы взаимодействия; агенты получают вознаграждение (reward) в формальных средах. Разработано для бенчмарка обучения с подкреплением (RL benchmark), поэтому использование с LLM требует интеграции и отдельной проверки интерфейса и действий (actions).

## Техническая реализация

https://github.com/google-deepmind/meltingpot; лицензия Apache-2.0. Нужна обёртка для LLM.
